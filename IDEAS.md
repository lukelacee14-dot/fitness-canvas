## Theme Packages / Skins (Monetization — Future)
Status: Not started. Deliberately deferred until after a proper designer pass on the base UI.

Concept: Purely cosmetic UI theme packages, similar to Fortnite's skin model — reskins of the app's visual style (e.g. Simple/Clean, Rustic Wood, Neon, and other styles to be designed later) that change appearance only, never functionality. Fits the app's core customization philosophy extended to visuals, not just tools.

Monetization: One-time purchase per theme (~$5 each), owned permanently once bought — a separate revenue stream alongside the subscription tiers, available to free and paid users alike.

Dependency: Requires a proper UI/graphic designer pass first — themes built on top of an AI-generated-looking base won't be worth selling. Revisit this once a designer is engaged and the core UI has been redesigned properly.
